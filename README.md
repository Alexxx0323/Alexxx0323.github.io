# Renfei (Alex) Zhang — personal website

Static academic homepage, served by GitHub Pages at https://alexxx0323.github.io/.

## Where to edit

| What | File |
|---|---|
| Page content (about, research interests, news, publications, links) | `index.html` |
| Layout, type and colours | `styles.css` |
| Phone menu and navigation highlighting | `script.js` |
| Profile photo and tab icon | `assets/` |

`.nojekyll` tells GitHub Pages to serve the files as they are.

## Previous version

The earlier Jekyll (Minimal Light) version of the site is saved on the `old-site` branch. To bring it back, restore that branch's files onto `main`.
